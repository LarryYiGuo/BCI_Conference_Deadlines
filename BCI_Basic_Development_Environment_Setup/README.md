# BCI 入门开发环境 · BCI Starter Environment

网页版(中英对照,推荐从这里看)/ Web page (bilingual, start here):
**https://larryyiguo.github.io/BCI_Conference_Deadlines/BCI_Basic_Development_Environment_Setup/**

给 BCI 入门者的 Python 环境:四步装好,每周在 macOS / Windows / Linux 上自动验证。
A Python environment for people starting out in BCI: four steps to install, re-verified weekly on macOS, Windows and Linux.

```bash
conda env create -f environment.yml
conda activate bci
python smoke_test.py
```

| 文件 / File | 作用 / Purpose |
|---|---|
| `environment.yml` | 入门者用这个。锁定到三平台都验证通过的版本,由 CI 生成。 / Use this one. Pinned to versions that passed on all three systems; generated by CI. |
| `smoke_test.py` | 装完跑一下,不下载数据,检查导入、包来源和三个最小流程。 / Run after installing. No downloads; checks imports, package sources and three mini pipelines. |
| `ci/spec.yml` | 松散规格,CI 每周用它装最新版本来测。要改依赖改这里。 / Loose spec CI uses to test the newest versions each week. Change dependencies here. |
| `ci/aggregate.py` | 汇总三平台结果;全部通过才更新 `environment.yml` 和 `verified.json`。 / Merges the three results; only updates `environment.yml` and `verified.json` when all pass. |
| `verified.json` | 已验证的版本、最近一次检查、历史记录。网页从这里读数据。 / Verified versions, latest check and history. The page reads from here. |
| `index.html` | 网页本身。 / The page itself. |

工作流 / Workflow: [`.github/workflows/env-verify.yml`](../.github/workflows/env-verify.yml)
