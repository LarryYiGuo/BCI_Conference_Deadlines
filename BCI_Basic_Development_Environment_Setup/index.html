BCI · Starter Environment

BCI 入门开发环境BCI starter environment

这一页带你在自己的电脑上装好一个 Python 环境，用来做脑电分析和深度学习。一共四步，大约半小时。This page walks you through installing a Python environment for EEG analysis and deep learning on your own computer. Four steps, about half an hour.

页面上的版本每周都会在 macOS、Windows、Linux 上各测一遍。三个系统都通过，版本才会更新。The versions on this page are re-tested every week on macOS, Windows and Linux. They only change when all three pass.

开始之前Before you start
Need
你需要什么What you need
一台电脑，Windows、macOS、Linux 都可以。大约 5 GB 空闲空间，以及能访问 GitHub 和 conda-forge 的网络。A computer running Windows, macOS or Linux, about 5 GB of free disk space, and a network that can reach GitHub and conda-forge.
Why
为什么用 MiniforgeWhy Miniforge

Miniforge 是 conda 的社区发行版，默认从 conda-forge 装包，体积小，免费。Miniforge is the community distribution of conda. It installs packages from conda-forge by default, and it is small and free.

已经装了 Anaconda 或 Miniconda 也可以直接用，跳过第一步。环境文件里写明了只用 conda-forge，不会走 Anaconda 的默认源。If you already have Anaconda or Miniconda, you can use it and skip step 1. The environment file only uses conda-forge, never Anaconda's default channel.

Env
为什么要单独建一个环境Why a separate environment
不同项目需要的包版本不一样，全装在一起迟早会冲突。单独的环境坏了可以删掉重建，不影响电脑上的其他东西。Different projects need different package versions, and putting everything in one place eventually breaks something. A separate environment can be deleted and rebuilt without touching anything else.

第二步 · 建环境Step 2 · Create the environment
Step
02
5–15 min
curl -O https://larryyiguo.github.io/BCI_Conference_Deadlines/BCI_Basic_Development_Environment_Setup/environment.yml
conda env create -f environment.yml
conda activate bci

第一行下载环境文件。第二行按文件装好所有包，大约要下载 0.5 到 1 GB。第三行进入这个环境。The first line downloads the environment file. The second installs everything in it, roughly a 0.5–1 GB download. The third enters the environment.

以后每次打开终端，都要先运行 conda activate bci。命令行开头出现 (bci)，就说明进来了。Every time you open a new terminal, run conda activate bci first. You are in when the prompt starts with (bci).

第三步 · 设数据目录Step 3 · Set the data folder
Step
03
1 min

MOABB 下载的公开数据集，一个就可能有好几 GB，默认放在用户目录下的 mne_data。想放到空间更大的盘，就设置 MNE_DATA。A single public dataset downloaded by MOABB can be several GB. By default it goes to mne_data in your home folder. To put it on a bigger disk, set MNE_DATA.

不要选 iCloud、OneDrive、坚果云这类会同步的文件夹，否则几个 GB 的数据会被反复上传。Do not pick a synced folder such as iCloud, OneDrive or Dropbox, or gigabytes of data will keep uploading.

conda env config vars set -n bci MNE_DATA=$HOME/mne_data
conda deactivate
conda activate bci
conda env config vars set -n bci MNE_DATA=%USERPROFILE%\mne_data
conda deactivate
conda activate bci
把路径换成你想放数据的位置。设置要重新进入环境后才生效，所以后两行不能省。Replace the path with wherever you want the data. The setting only takes effect after re-entering the environment, so keep the last two lines.
第四步 · 验证Step 4 · Verify
Step
04
1–2 min
curl -O https://larryyiguo.github.io/BCI_Conference_Deadlines/BCI_Basic_Development_Environment_Setup/smoke_test.py
python smoke_test.py

这个脚本不下载任何数据。它逐个导入核心包，检查编译型的包是不是都来自 conda，再用合成脑电跑一遍 CSP、黎曼分类器和一个小神经网络。The script downloads no data. It imports each core package, checks that compiled packages all came from conda, then runs CSP, a Riemannian classifier and a small neural network on synthetic EEG.

最后一行是 RESULT: ALL PASSED 就可以开始学了。第一次运行要一两分钟，之后十几秒。出现 FAIL，先看是哪一行，再对照下面的「常见坑」。If the last line reads RESULT: ALL PASSED, you are ready. The first run takes a minute or two; later runs take about ten seconds. If something says FAIL, find that line and check the pitfalls below.

装了什么What's inside

PyPI 上有更新，不代表你该升级。新版本要在三个系统上都通过测试，才会出现在大数字的位置。A newer version on PyPI is not a reason to upgrade. It only becomes the large number after passing on all three systems.

这一页怎么保持更新How this page stays current

每周一，GitHub Actions 会在 macOS、Windows、Linux 的虚拟机上各从零建一次环境，装当时能装到的最新版本，再跑同一个 smoke_test.py。Every Monday, GitHub Actions builds the environment from scratch on macOS, Windows and Linux virtual machines with the newest versions available, then runs the same smoke_test.py.

三个系统都通过，本页的版本和 environment.yml 才会更新。有一个失败，就保留上一次通过的版本，并在下面标出是哪个系统失败了。Only when all three pass do the versions on this page and environment.yml change. If one fails, the last passing versions stay, and the failing system is marked below.
